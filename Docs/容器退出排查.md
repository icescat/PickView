# 容器启动后退出排查

## 问题现象
容器启动后立即退出（Exited:0）

## 排查步骤

### 1. 查看详细日志

```bash
# 查看完整日志
docker logs bilipick-server

# 或查看最后50行
docker logs --tail 50 bilipick-server
```

### 2. 检查Python代码错误

进入容器目录，手动测试：

```bash
cd /vol1/1000/docker/bilipick

# 查看文件是否存在
ls -la app/

# 检查Python语法
docker run --rm -v $(pwd)/app:/app python:3.11-slim python -m py_compile /app/main.py
```

### 3. 常见错误及修复

#### 错误1：Python缩进错误

**现象：**
```
IndentationError: unexpected indent
```

**修复：**
检查 `app/main.py` 和 `app/database.py` 的缩进，确保使用4个空格。

#### 错误2：导入错误

**现象：**
```
ModuleNotFoundError: No module named 'fastapi'
```

**修复：**
```bash
# 重新构建镜像
docker-compose down
docker rmi bilipick-server
docker-compose up -d --build
```

#### 错误3：数据库目录权限

**现象：**
```
PermissionError: [Errno 13] Permission denied: '/app/data'
```

**修复：**
```bash
# 修复权限
chmod -R 777 /vol1/1000/docker/bilipick/data

# 或修改docker-compose.yml添加用户
# user: "0:0"
```

#### 错误4：相对导入错误

**现象：**
```
ImportError: attempted relative import with no known parent package
```

**修复：**
修改 `app/main.py` 中的导入语句：
```python
# 从
from .models import VideoCreate, VideoResponse
from .database import db

# 改为
from models import VideoCreate, VideoResponse
from database import db
```

### 4. 手动运行测试

```bash
cd /vol1/1000/docker/bilipick

# 进入容器手动运行
docker run -it --rm -v $(pwd)/app:/app -v $(pwd)/data:/app/data -p 9525:9525 python:3.11-slim bash

# 在容器内
pip install fastapi uvicorn pydantic
cd /app
uvicorn main:app --host 0.0.0.0 --port 9525
```

### 5. 修复docker-compose.yml

如果以上都不行，尝试简化配置：

```yaml
# 删除 version 行（已过时）
services:
  bilipick-server:
    image: python:3.11-slim
    container_name: bilipick-server
    working_dir: /app
    command: >
      sh -c "pip install fastapi uvicorn pydantic -q &&
             uvicorn main:app --host 0.0.0.0 --port 9525"
    ports:
      - "9525:9525"
    volumes:
      - ./app:/app
      - ./data:/app/data
    restart: unless-stopped
    environment:
      - TZ=Asia/Shanghai
```

### 6. 快速修复脚本

```bash
#!/bin/bash

cd /vol1/1000/docker/bilipick

# 停止并删除
docker-compose down
docker rm -f bilipick-server 2>/dev/null
docker rmi bilipick-server 2>/dev/null

# 修复权限
mkdir -p data
chmod -R 777 data

# 重新构建
docker-compose up -d --build

# 查看日志
sleep 3
docker logs --tail 30 bilipick-server
```
