# 容器启动失败排查

## 问题现象
容器创建成功但立即退出（Exited:0）

## 排查命令

请按顺序执行以下命令：

### 1. 查看容器状态
```bash
sudo docker ps -a | grep bilipick
```

### 2. 查看容器日志（关键）
```bash
sudo docker logs bilipick-server
```

### 3. 如果日志为空，查看容器错误
```bash
sudo docker inspect bilipick-server | grep -A 10 "State"
```

### 4. 手动运行测试
```bash
cd /vol1/1000/docker/bilipick

# 手动运行容器，查看错误
docker run --rm -v $(pwd)/app:/app -v $(pwd)/data:/app/data -p 9530:9525 python:3.11-slim bash -c "pip install fastapi uvicorn pydantic -q && cd /app && uvicorn main:app --host 0.0.0.0 --port 9525"
```

## 常见错误

### 错误1：Python文件不存在
```
Error: [Errno 2] No such file or directory: '/app/main.py'
```
**解决：** 检查app目录下是否有main.py文件

### 错误2：Python导入错误
```
ImportError: attempted relative import with no known parent package
```
**解决：** 修改main.py中的导入语句

### 错误3：端口被占用
```
Address already in use
```
**解决：** 更换端口

### 错误4：权限错误
```
PermissionError: [Errno 13] Permission denied
```
**解决：** chmod 777 data

## 快速修复

如果排查太麻烦，直接用简化版配置：

```bash
cd /vol1/1000/docker/bilipick

# 备份原配置
sudo cp docker-compose.yml docker-compose.yml.bak

# 创建简化版配置
cat > docker-compose.yml << 'EOF'
services:
  bilipick-server:
    image: python:3.11-slim
    container_name: bilipick-server
    working_dir: /app
    command: >
      sh -c "pip install fastapi uvicorn pydantic -q &&
             python -c 'import sys; sys.path.insert(0, \"/app\"); from main import app; import uvicorn; uvicorn.run(app, host=\"0.0.0.0\", port=9525)'"
    ports:
      - "9530:9525"
    volumes:
      - ./app:/app
      - ./data:/app/data
    restart: unless-stopped
    environment:
      - TZ=Asia/Shanghai
      - PYTHONPATH=/app
EOF

# 修改main.py导入
cd app
sudo sed -i 's/from \.models/from models/g' main.py
sudo sed -i 's/from \.database/from database/g' main.py

# 修改database.py导入
sudo sed -i 's/from \.models/from models/g' database.py

cd /vol1/1000/docker/bilipick

# 重新启动
sudo docker-compose down
sudo docker rmi bilipick-bilipick-server 2>/dev/null
sudo docker-compose up -d

# 查看日志
sleep 3
sudo docker logs bilipick-server
```
