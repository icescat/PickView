# 服务反复重启问题排查

## 问题现象
日志显示服务不断重启：
```
INFO:     Started server process [1]
INFO:     Shutting down
INFO:     Started server process [1]
INFO:     Shutting down
...
```

## 可能原因

1. **端口冲突** - 9530端口被其他程序占用
2. **权限问题** - 无法写入数据目录
3. **Docker配置错误** - 端口映射或网络问题
4. **健康检查失败** - 飞牛Docker套件的健康检查配置

## 排查步骤

### 1. 检查端口占用

```bash
# 查看9530端口是否被占用
sudo netstat -tlnp | grep 9530
sudo lsof -i :9530
```

### 2. 检查Docker端口映射

```bash
sudo docker ps | grep bilipick
# 应该显示：0.0.0.0:9530->9525/tcp
```

### 3. 查看详细错误

```bash
# 查看最后100行日志
sudo docker logs --tail 100 bilipick-server

# 查看容器事件
sudo docker events --filter container=bilipick-server
```

### 4. 检查数据目录权限

```bash
ls -la /vol1/1000/docker/bilipick/data/
```

### 5. 检查docker-compose配置

```bash
cat /vol1/1000/docker/bilipick/docker-compose.yml
```

## 快速修复方案

### 方案1：更换端口（如果9530被占用）

```bash
cd /vol1/1000/docker/bilipick

# 停止服务
sudo docker-compose down

# 改为9540端口
sudo sed -i 's/9530:9525/9540:9525/g' docker-compose.yml

# 启动
sudo docker-compose up -d

# 测试
curl http://localhost:9540
```

### 方案2：简化配置（排除构建问题）

直接修改 `docker-compose.yml` 为：

```yaml
services:
  bilipick-server:
    image: python:3.11-slim
    container_name: bilipick-server
    working_dir: /app
    command: >
      sh -c "pip install fastapi uvicorn pydantic -q &&
             uvicorn main:app --host 0.0.0.0 --port 9525"
    ports:
      - "9530:9525"
    volumes:
      - ./app:/app
      - ./data:/app/data
    restart: unless-stopped
    environment:
      - TZ=Asia/Shanghai
```

然后：
```bash
sudo docker-compose down
sudo docker rmi bilipick-bilipick-server 2>/dev/null
sudo docker-compose up -d
```

### 方案3：检查飞牛Docker健康检查

如果飞牛Docker套件配置了健康检查，可能会频繁重启容器。

在飞牛Web界面：
1. 打开 Docker 应用
2. 找到 bilipick-server 容器
3. 检查是否有健康检查配置
4. 暂时禁用健康检查测试

## 诊断脚本

```bash
#!/bin/bash

echo "=== 服务诊断 ==="
echo ""

echo "1. 容器状态："
sudo docker ps -a | grep bilipick
echo ""

echo "2. 端口监听："
sudo netstat -tlnp 2>/dev/null | grep -E "(9530|9525)" || sudo ss -tlnp | grep -E "(9530|9525)"
echo ""

echo "3. 目录权限："
ls -la /vol1/1000/docker/bilipick/
ls -la /vol1/1000/docker/bilipick/data/ 2>/dev/null || echo "data目录不存在"
echo ""

echo "4. 配置文件："
cat /vol1/1000/docker/bilipick/docker-compose.yml
echo ""

echo "5. 最近日志："
sudo docker logs --tail 30 bilipick-server 2>&1
echo ""

echo "=== 诊断完成 ==="
```

保存并执行：
```bash
chmod +x diagnose.sh
./diagnose.sh
```
