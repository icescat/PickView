# 修改服务端口为9530

## 操作步骤

### 1. 修改 docker-compose.yml

```bash
cd /vol1/1000/docker/bilipick

# 编辑文件
sudo nano docker-compose.yml
```

修改为：
```yaml
services:
  bilipick-server:
    build: .
    container_name: bilipick-server
    ports:
      - "9530:9525"  # 外部9530映射到内部9525
    volumes:
      - ./data:/app/data
    restart: unless-stopped
    environment:
      - TZ=Asia/Shanghai
```

### 2. 重启容器

```bash
sudo docker-compose down
sudo docker-compose up -d
```

### 3. 验证

```bash
# 检查端口映射
sudo docker ps | grep bilipick
# 应该显示：0.0.0.0:9530->9525/tcp

# 测试访问
curl http://localhost:9530
```

### 4. 手机APP配置

服务器地址改为：
```
http://你的NAS_IP:9530
```

---

## 完整命令

```bash
cd /vol1/1000/docker/bilipick

# 停止服务
sudo docker-compose down

# 修改配置（用sed一键替换）
sudo sed -i 's/9525:9525/9530:9525/g' docker-compose.yml

# 启动服务
sudo docker-compose up -d

# 验证
curl http://localhost:9530
```

---

## 注意事项

- 内部端口保持9525（服务监听端口）
- 外部端口改为9530（访问端口）
- 手机APP需要更新服务器地址
