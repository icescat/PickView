# 故障排查指南

## 问题：构建完成但无法访问页面

### 排查步骤

#### 1. 检查容器是否运行

```bash
# 查看容器状态
docker ps | grep bilipick

# 应该显示类似：
# CONTAINER ID   IMAGE                  STATUS         PORTS
# xxxxxxx        bilipick-server        Up 2 minutes   0.0.0.0:9525->9525/tcp
```

**如果没有显示：**
```bash
# 查看所有容器（包括已停止的）
docker ps -a | grep bilipick

# 查看容器日志
docker logs bilipick-server
```

#### 2. 检查端口映射

```bash
# 查看端口监听
netstat -tlnp | grep 9525

# 或
ss -tlnp | grep 9525
```

**应该显示：**
```
tcp    0    0 0.0.0.0:9525    0.0.0.0:*    LISTEN    xxxx/docker-proxy
```

#### 3. 测试本地访问

在NAS上执行：
```bash
# 测试本地访问
curl http://localhost:9525

# 或
curl http://127.0.0.1:9525
```

**如果本地可以访问，但外网不行 → 防火墙问题**
**如果本地也无法访问 → 服务问题**

#### 4. 检查防火墙

```bash
# 查看防火墙规则
iptables -L -n | grep 9525

# 临时关闭防火墙测试（谨慎操作）
iptables -F

# 或添加允许规则
iptables -A INPUT -p tcp --dport 9525 -j ACCEPT
```

#### 5. 检查飞牛OS防火墙

通过Web界面：
1. 打开飞牛Web界面
2. 进入 **设置** → **安全** → **防火墙**
3. 添加规则：允许 TCP 9525 端口

#### 6. 查看详细日志

```bash
# 进入容器目录
cd /docker/bilipick-server

# 查看日志
docker-compose logs

# 或实时查看
docker-compose logs -f
```

**常见问题日志：**
- `Address already in use` → 端口被占用
- `Permission denied` → 权限问题
- `Module not found` → 依赖问题

#### 7. 检查文件权限

```bash
# 检查数据目录权限
ls -la /docker/bilipick-server/

# 确保有写入权限
chmod 755 /docker/bilipick-server/data
```

#### 8. 重建容器

如果以上都正常，尝试重建：

```bash
cd /docker/bilipick-server

# 停止并删除容器
docker-compose down

# 删除镜像（强制重新构建）
docker rmi bilipick-server

# 重新构建并启动
docker-compose up -d --build

# 查看日志
docker-compose logs -f
```

## 常见错误及解决

### 错误1：端口被占用

**现象：**
```
Error starting userland proxy: listen tcp4 0.0.0.0:9525: bind: address already in use
```

**解决：**
```bash
# 查看占用进程
lsof -i :9525

# 或
netstat -tlnp | grep 9525

# 修改 docker-compose.yml，更换端口
# ports:
#   - "9526:9525"  # 改为9526
```

### 错误2：Python依赖下载失败

**现象：**
```
ERROR: Could not find a version that satisfies the requirement
```

**解决：**
```bash
# 检查网络
curl -I https://pypi.org

# 或更换国内镜像
cat > requirements.txt << 'EOF'
fastapi==0.104.1
uvicorn[standard]==0.24.0
pydantic==2.5.0
-i https://pypi.tuna.tsinghua.edu.cn/simple
EOF
```

### 错误3：权限拒绝

**现象：**
```
PermissionError: [Errno 13] Permission denied: '/app/data'
```

**解决：**
```bash
# 修复权限
chmod -R 777 /docker/bilipick-server/data

# 或修改docker-compose.yml，添加用户映射
# user: "1000:1000"
```

### 错误4：CORS问题（手机访问）

如果手机无法访问，但电脑可以：

**检查：**
```bash
# 在手机上用浏览器访问
http://NAS_IP:9525

# 如果显示CORS错误，检查main.py中的CORS配置
```

**已在代码中配置允许所有来源，通常不会有问题。**

## 快速诊断脚本

在NAS上执行以下脚本，自动诊断问题：

```bash
#!/bin/bash

echo "=== B站精选服务端诊断 ==="
echo ""

echo "1. 检查容器状态："
docker ps | grep bilipick || echo "❌ 容器未运行"
echo ""

echo "2. 检查端口监听："
netstat -tlnp 2>/dev/null | grep 9525 || ss -tlnp | grep 9525 || echo "❌ 端口未监听"
echo ""

echo "3. 测试本地访问："
curl -s http://localhost:9525 && echo "" || echo "❌ 本地访问失败"
echo ""

echo "4. 检查防火墙："
iptables -L -n | grep 9525 || echo "⚠️ 未找到9525防火墙规则"
echo ""

echo "5. 查看最近日志："
docker logs --tail 20 bilipick-server 2>/dev/null || echo "❌ 无法获取日志"
echo ""

echo "=== 诊断完成 ==="
```

保存为 `diagnose.sh`，然后执行：
```bash
chmod +x diagnose.sh
./diagnose.sh
```
