# 家长控制系统实施计划

## 总体目标

打造一个完整的家长控制视频播放生态：
1. 手机端推送视频到NAS
2. TV端从NAS获取并播放
3. 完整的观看限制功能

## 第一阶段：手机端推送功能

### 阶段目标
家长可以通过Android手机将B站视频推送到飞牛NAS，并在NAS上查看精选视频列表。

### 实施步骤

#### 1.1 搭建NAS服务端（Python FastAPI）

**任务清单：**
- [ ] 创建FastAPI项目结构
- [ ] 设计数据库模型（SQLite）
- [ ] 实现视频CRUD接口
- [ ] 实现视频列表查询接口
- [ ] 添加CORS支持（允许手机端访问）
- [ ] 部署到飞牛NAS

**文件结构：**
```
server/
├── app/
│   ├── __init__.py
│   ├── main.py              # FastAPI入口
│   ├── models.py            # 数据库模型
│   ├── schemas.py           # Pydantic模型
│   ├── crud.py              # 数据库操作
│   └── database.py          # 数据库连接
├── requirements.txt
└── run.py                   # 启动脚本
```

**API接口：**
- `POST /api/videos` - 添加视频
- `GET /api/videos` - 获取视频列表
- `GET /api/videos/{id}` - 获取单个视频
- `DELETE /api/videos/{id}` - 删除视频

#### 1.2 开发家长管理APP（Android）

**任务清单：**
- [ ] 创建Android项目（Kotlin + Jetpack Compose）
- [ ] 实现分享接收功能（接收B站分享）
- [ ] 实现BV号解析功能
- [ ] 调用B站API获取视频详情
- [ ] 实现视频推送到NAS功能
- [ ] 实现视频列表查看/删除功能
- [ ] 配置NAS服务器地址

**核心功能：**
1. **分享接收**
   - 注册分享接收器，接收B站APP的分享
   - 解析分享链接，提取BV号

2. **视频详情获取**
   - 调用B站API获取视频信息
   - 提取：标题、封面、时长、UP主

3. **推送到NAS**
   - HTTP POST请求发送视频信息
   - 显示推送成功/失败提示

4. **视频管理**
   - 显示已推送的视频列表
   - 支持删除视频

**界面设计：**
- 首页：视频列表（网格布局）
- 底部：添加按钮、设置按钮
- 设置页：NAS服务器地址配置

#### 1.3 测试验证

**测试场景：**
1. 在B站APP中找到视频，点击分享
2. 选择"家长管理APP"
3. APP解析并显示视频信息
4. 点击"推送到NAS"
5. 在NAS管理界面查看视频列表

**验收标准：**
- [ ] 可以成功接收B站分享
- [ ] 可以正确解析视频信息
- [ ] 可以成功推送到NAS
- [ ] 可以在NAS上查看视频列表

## 开发顺序建议

### 推荐顺序

1. **先开发NAS服务端**（基础）
   - 搭建FastAPI框架
   - 实现视频CRUD
   - 部署到飞牛NAS

2. **再开发家长管理APP**（内容来源）
   - 实现分享接收
   - 实现视频推送
   - 测试可以成功推送视频

3. **最后改造TV端**（内容消费）
   - 删除无关功能
   - 实现精选视频列表
   - 实现观看限制

### 原因

- NAS服务端是基础，必须先有
- 家长管理APP提供内容，没有内容TV端无法测试
- TV端改造最复杂，放在最后

## 技术栈确认

| 组件 | 技术栈 |
|------|--------|
| NAS服务端 | Python 3.10+ + FastAPI + SQLite |
| 家长管理APP | Kotlin + Jetpack Compose + Retrofit |
| TV播放器 | 现有BV项目（Kotlin + Jetpack Compose） |
| 通信协议 | HTTP REST API + JSON |

---

## 风险与应对

| 风险 | 应对措施 |
|------|----------|
| B站API变动 | 使用稳定的API，添加错误处理 |
| 网络不稳定 | 添加重试机制，本地缓存 |
| 孩子破解 | 添加PIN码验证，服务端校验 |
| NAS服务宕机 | 添加离线模式，本地缓存视频列表 |
